Atreia-Assistant 是一把为《永恒之塔2》冒险者打造的社区锻造之作，目标是把简体中文汉化、DPS 战斗统计与技能伤害复盘收进同一只工具箱里。它当前仍处于开发版，接口与行为都可能随实战反馈继续打磨，兼容性也等待更多真实战场来验证。愿意一起试刀、报错、提建议的玩家，都是这个项目最需要的同行者。

## Features

**功能亮点**

- **战斗统计浮窗**：开启统计后，游戏内会出现小型透明置顶浮窗，实时查看 DPS、总伤害、玩家贡献与技能明细，不遮挡视野。
- **伤害与治疗分析**：除输出排行外，还支持治疗量统计与本地战斗历史回放，方便复盘每一场战斗。
- **技能伤害拆解**：按技能维度分析伤害构成，找出输出瓶颈，为下一轮循环优化提供依据。
- **简体中文汉化**：面向 Steam / Global 与 PURPLE 客户端提供检测、安装、更新与还原入口；汉化前请先退出游戏，并确认客户端与游戏目录。
- **功能彼此独立**：首页打开或进入汉化页面不会启动抓包；只有主动开启统计后才显示游戏悬浮窗。统计与汉化分属两条互不干扰的流程。
- **本地处理，安心复盘**：统计在本机完成，不自动上传战斗数据，不注入游戏进程、不修改游戏内存。
- **自动识别战斗通道**：无需手动填写 IP、端口，也不必纠结加速器品牌，进入游戏开启统计即可。

当前为开发版，汉化、DPS 统计、技能伤害分析与复盘正在逐步整合，实战兼容性仍待验证。欢迎在游玩中记录异常、反馈体验，一起把这个助手打磨成真正顺手的冒险伙伴。

## Installation & Setup

欢迎登上前往亚特雷亚的航班。在你打开助手之前，先把这几步走完——不复杂，但每一步都值得认真对待。

**第一步：把助手请进你的机器**

亚特雷亚助手以 Windows 安装包的形式发布，命名规则清晰可辨：`Atreia-Assistant_<version>_x64.msi`。拿到它，双击，跟着 Windows 安装向导走完即可。安装器会在你的桌面上留下一个名为 `Atreia Assistant` 的快捷方式，卸载时也会由 Windows 安装器干净地收回——不留尾巴。如果你用的是便携版可执行文件，则不会自动生成快捷方式，需要你自己记住它的位置。

请认准安装包本体，不要误取源码压缩包——那是给愿意读代码、动手改造的人准备的，不是给准备开玩的人准备的。

**第二步：先决定你想让助手做什么**

启动助手后，首页会递给你两个选择：**战斗统计**，或者**游戏汉化**。它们彼此独立，互不干扰——打开首页或汉化页面不会悄悄启动任何抓包，汉化入口也不会藏在统计浮窗里。你选了哪条路，助手就走哪条路。

**第三步：若你选择战斗统计**

首次开启统计前，需要系统里已经装好 Npcap 驱动。如果它已经在你的机器上安家，跳过即可，不必重复安装。你不需要额外下载 SDK，也不需要勾选 WinPcap 兼容模式——助手只处理本机收到的游戏数据，不注入游戏、不修改游戏内存，战斗数据全程留在本地，不会自动上传。

进入游戏后开启统计，确认采集提示，透明置顶的小浮窗就会浮现，DPS、总伤害、玩家贡献与技能明细尽收眼底。建议把游戏切到窗口或无边框窗口模式，浮窗才好安放。想收工的时候，在统计设置里选择“停止统计并返回首页”，再从容切换到汉化功能。

**第四步：若你选择游戏汉化**

汉化之前，请先退出游戏。这一步没有商量余地。然后确认客户端与游戏目录，让助手完成检测、安装、更新或还原的流程。汉化会修改本地语言资源，并配有备份与还原机制，所以不必担心一去不回。

有一点值得记在心里：升级助手本身不会动你的游戏资源。如果你升级了安装包，请退出游戏，再回到汉化页面重新检测并安装汉化，让译文与当前版本重新对齐。

**第五步：让助手保持新鲜**

桌面助手首页支持在启动时自动检查本项目正式版本，也支持手动检查、确认后下载更新并显示进度。更新包会经过 SHA-256 与大小校验，确保到你手里的东西没有被掉包。唯一的规矩是：统计或汉化事务正在进行时，更新会被拦下——先把手头的活儿收尾，再谈升级。

## Compatibility & Verification

亚特雷亚助手当前处于**开发版**阶段——功能骨架已经搭好，实战兼容性仍在逐项验证中。我们不希望用“完美适配”的空话把你骗进战场，所以这里把已知边界摊开讲清楚：哪些环境跑过、哪些还没验收、遇到问题怎么反馈。

**当前验证基线**

- 目标平台为《永恒之塔2》Steam 与 PURPLE 客户端，助手按这两条入口分别对待，不假设二者资源结构一致。
- 汉化组件以本地语言资源为基准做键值校验与隔离安装，安装与还原流程已在受控环境中走通；但游戏内每一处界面尚未逐一截图验收，个别文本可能仍是“待校对”状态。
- DPS 战斗统计走本机数据采集路线，不注入游戏进程、不修改游戏内存。战斗通道的自动识别在开发环境可用，跨版本、跨网络环境下的稳定性仍需实战样本喂养。
- 简体中文汉化、DPS 统计、技能伤害分析与复盘为规划中的整合方向，当前开发版可能只开放部分入口，未点亮的功能不代表已验收。

**你需要知道的兼容性边界**

- 游戏每次更新都可能改动语言资源键位或战斗数据结构，助手不会假装无事发生——更新后请重新执行检测，旧译文不会强行套用到新文本上。
- 汉化操作前请退出游戏并确认客户端目录；统计与汉化建议分开进行，避免资源占用互相干扰。
- 助手仅处理本机收到的游戏数据，不上传战斗记录，不提供第三方账号登录入口。你的战斗数据留在你自己的机器上。
- 若你使用窗口或无边框窗口模式，悬浮统计窗的体验会更稳；全屏独占下的表现属于待验证项。

**验证与反馈**

开发版的价值在于“一起把它跑稳”。如果你在 Steam 或 PURPLE 上遇到汉化缺字、统计断流、悬浮窗异常或还原失败，请记录你的客户端来源、游戏版本号与复现步骤，通过项目仓库的反馈渠道提交。每一条实战报告都会进入兼容性核对清单，帮助我们把“待验证”变成“已验收”。

在官方验收清单清空之前，请把本助手当作一位正在磨合期的队友：能打，但别把整场团本的胜负押在它身上。
